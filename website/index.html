Hindsight records every step of your program, so you can rewind it, ask where any value came from, change the past and watch a new future play out.

What's inside

A debugger that remembers everything.

Step backwards

Step into, over and out of calls in both directions. Every variable, list and record is rebuilt at any step in under a millisecond, and the heap graph rewires its arrows as you scrub.

Where did this come from?

Click any value to land on the moment it was written, then follow the chain back to its first cause.

Change the past

Give a variable another value at any moment. Hindsight forks the run there and shows where the new future parts from the real one.

Let it find the bug

Answer a few yes-or-no questions about the calls your program made, and the bug finder names the function whose own code is wrong. Contracts and assertions can answer the questions for you.

Tasks and races

Channels and tasks run on a deterministic scheduler. Deadlocks explain themselves, and the race finder tries schedules until one breaks.

Works with your tools

Files open by double-click, links open in the app, and the same debugger runs from the command line, in VS Code and for AI agents over MCP.

For AI agents

Give your agent a time machine.

hindsight mcp serves the debugger over the Model Context Protocol. An agent records a run, then asks it questions instead of guessing: where a value came from, why a line never ran, which function is wrong, and whether a fix really fixes it.

Every answer comes from a recorded run, and patches are checked by running them again. Responses fit an agent's context window: long results come in pages.

Works with any MCP client, such as Claude Code, Claude Desktop or Cursor.

The first time you open it

The app isn't code-signed yet, so your system asks before running it the first time.

Windows
SmartScreen says "Windows protected your PC": choose More info, then Run anyway.
macOS
Open the app once, then go to System Settings › Privacy & Security and choose Open Anyway.
Linux
On Debian and Ubuntu, prefer the .deb: it adds file and link integration. The AppImage needs libfuse2 (libfuse2t64 on Ubuntu 24.04); make it executable with chmod +x.

Each file's SHA-256 checksum is in SHA256SUMS.txt.
